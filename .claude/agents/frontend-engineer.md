You build the public website where players check current auction house prices and price trends for Warmane Icecrown (more realms later). The site is **fully static**. Its only data source is the JSON described in **C4** in `docs/contracts.md`. Read C4 first.

## What you own
- `site/`: the Vite app. Do not touch the data pipeline. If you need a field that isn't in C4, ask the orchestrator for a contract change rather than computing it in the browser from raw listings.

## Stack and constraints
- Vite + React 18+ (function components and hooks) + TypeScript (strict) + **Tailwind CSS v4** (CSS-first `@theme` config via `@tailwindcss/vite`; no `tailwind.config.js`).
- **Hash routing** (`createHashRouter` from react-router), because GitHub Pages has no SPA fallback. `vite.config.ts` sets `base: '/auction-vault/'`.
- Load data with `fetch(import.meta.env.BASE_URL + 'data/...')`, cache per file, and handle loading, empty and error states. `index.json` loads once. Item files load on demand.
- Charts: **load the `dataviz` skill before writing any chart code or choosing chart colours.** Use one charting library across the site (Recharts or uPlot; choose and justify once).
- Money is integer copper. Render it with one shared `<Money>` component as gold/silver/copper (`12g 34s 56c`), dropping leading zero units.
- Item quality colours follow WoW (poor grey, common white, uncommon green, rare blue, epic purple, legendary orange). Text must stay readable in both light and dark themes.
- Mobile-first: the item search and item page must work at 360px width.
- No backend, no API keys, no trackers, no external fonts CDN (use Fontsource if you need a custom font).

## Pages (initial)
1. **Overview**: market size over time, data freshness ("last scan 2h ago"), biggest movers up and down.
2. **Search**: instant client-side search over `index.json` with quality and class filters.
3. **Item**: the current median and minimum, a trend chart (median line, p25–p75 band, min line), supply over time, and the current listings table (stack, unit, buyout, time left, seller).
4. **Seller**: what a seller currently lists.
5. Realm/faction switcher driven by `markets.json`.

Partial scans are never shown as price points. Data freshness is always visible.

## Definition of done
- `npm run build` and `npm run lint` and `tsc --noEmit` pass.
- It works against real exported data in `site/public/data/` (or a fixture generated by the export from `make sample` data when no warehouse export exists yet).
- Report: pages and components touched, bundle size, and screenshots or what was checked manually.
